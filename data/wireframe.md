## 인터랙션

- 퀘스트 [완료] 탭 → 즉시 XP 애니메이션 + 사운드(옵션)
- 퀘스트 [건너뜀] 탭 → 사유 모달 자동 표시
- 모든 퀘스트 완료 → 축하 애니메이션 + 보스 진행도 업데이트
- 매일 5시: 백그라운드에서 quest JSON fetch → 홈 화면 자동 갱신
- 23:00 알림: "오늘 마감, 회고 작성하세요"

- 클로드는 매일 5시 logs/, inbox/ 읽고 다음날 quest 생성
